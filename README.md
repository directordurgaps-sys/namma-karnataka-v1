# NAMMA KARNATAKA

## YouTube + OTT Digital Platform

NAMMA KARNATAKA is a digital video and OTT platform designed to bring entertainment, information, creator content, and premium movies together in one application.

## Main Features

- User Registration & Login
- Creator / Channel Accounts
- Video Upload & Streaming
- Shorts
- Live Streaming
- Like, Comment, Share & Subscribe
- OTT Movies
- Free & Premium Content
- Subscription Plans
- Rent / Buy Movies
- Creator Earnings
- Payment Integration
- Search & Recommendations
- Notifications
- Admin Panel
- Android App
- Web Platform
